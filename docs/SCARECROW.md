# 稻草人内容与装备（2026-11-17）

后续玩家受击更新见 [五tick窗口与晃动](SCARECROW-HITS.md)；本页伤害段落保留为 scarecrow-v1 历史差异。

固定来源为 KaleidoscopeCookery `2f4e386ce23f49a385ddf003c67fc6415c55417a`。本批接入可放置物品、三组分体模型、来源合成配方，修正已有控制器的装备规则与持久化。来源角色是 LivingEntity，当前仍用 CE 家具承载；完整实体行为尚未复刻。

装备按来源交互：手部区域持耐久物品时先填主手，再填副手，满时不替换；空手则先取主手，再取副手。普通灯笼不属于耐久物品，不再作为新输入接受；旧存档已有灯笼仍保留且可取回。头部只接受头颅/骷髅头。创造模式仅在空头槽免费放一件；已有头颅时，手中恰好一件会交换，多件不交换。手部放工具的创造模式不扣物。命名牌返回 PASS，命名流程未在本批接入。

进入头/手处理器立即开始五个游戏 tick 冷却，无效输入也触发；此前使用墙钟并仅在成功时限速，与来源不同。副手、旁观者、无效家具、保护和区域所有权拒绝修改。交换前验证完整三槽存档及 CE 持久化编码，检查手中物品未被替换，再更新背包与装备；重入拒绝。空手取回按来源合并已有同组件堆叠、再填空格，物品数据保持完整。写入后抛异常会在仍拥有目标状态时回滚。

存档严格检查槽位、重复项、单件计数与解码结果，坏档保留原始数据并阻止操作。`item(slot)` 返回副本。确认移除后才发放装备，重复回调不重复发放；创造拆除丢弃装备，与来源一致。掉落事件取消时保留剩余内容到厨房插件数据目录 `recovery/scarecrow-*.nbt`，管理员核对后恢复，不自动发放。移除发生在交换重入期间时，完成或回滚后再结算装备。

模型从 Java 层级转换全部 13 个立方体/平面，保留两处 mirror UV 和 128×128 来源贴图。`scarecrow_body` 含11块（含头）、`scarecrow_headless` 含10块、`scarecrow_hat` 含2块；戴头颅时同时隐藏默认头和帽。为适配旧版 JSON 坐标上限，静态模型按中心缩至一半并在显示实体还原2倍；帽子以独立显示实体应用 `-.2182` 弧度倾斜，避免把来源角度改成旧版允许的22.5°。实际头颅、手持工具与帽子位置仍需客户端画面对照。

物品以八方向摆放，命中区域使用来源手部 `17/16..27/17` 高度带和其上的头部。来源中的 `27/17` 按原值保留。新增配方：草帽、南瓜、木棍和稻草捆标签。厨房配方配置达到 **612/612 imported**；配置全数导入不表示对应物品获取、自动化、玩家流程和世界行为全部完成。厨房包现有1,432物品、81方块、25家具、1,490可达模型。

- CE 家具固定，尚无来源重力、矿车乘坐及实体碰撞；放置碰撞/实体检查、下表面拒绝和来源事件不完整。
- 两次击打的五tick窗口、首击摆动/释放鹦鹉、爆炸仅掉装备、命名物品掉落仍未对齐；通用CE两击拆除不等价。
- 鹦鹉仍使用旧版肩膀载具逻辑，没有来源完整实体NBT、距离、环境和释放时机语义。
