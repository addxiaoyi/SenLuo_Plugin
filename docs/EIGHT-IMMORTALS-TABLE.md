# 八仙桌开发检查点

2026-11-17，固定 Cookery 来源 `2f4e386ce23f49a385ddf003c67fc6415c55417a`。本批实现八仙桌四格放置、关联拆除与资源导入。服务器和原版客户端尚未验收。

八仙桌占水平 2×2 格，朝向与玩家相同。右下为点击锚点，左下位于朝向逆时针方向，右上在前方，左上同时向左及向前；四方向共 16 个模型状态。没有物品桌面功能。来源合成配方、硬度 2、抗爆 3、竹木声音、阻挡活塞和 survives_explosion 单件掉落配置已导入。

放置使用专用四格事务。每格检查加载、当前区域、建造高度、世界边界、可替换性、来源顶部四分之一形状的实体碰撞、原生 mayUseItemAt 和保护权限。四次尝试事件后写入；触发一次包含四格快照的 Bukkit BlockMultiPlaceEvent、一次 CE 放置事件及配置函数。任意取消或写入失败均尝试恢复仍由本次事务持有的快照，不覆盖回调放入的替代物。最终重新确认玩家、手持物、四个控制器身份、朝向与部件，再扣除一个物品；创造模式不扣。递归放置和事务内破坏被拒绝。

四个部件保存相同 UUID 与 schema=1。拆除一格时只清理同组、同类型、同朝向且部件匹配的其他格，不再掉落；异组替代物保留。玩家破坏会对整桌逐格检查保护并发出关联 Bukkit 破坏事件；任一取消、替换、离线或状态变更均取消原破坏。最终回调后重新检查全部身份，避免先检查的部件被后续回调替换。跨区域清理捕获稳定世界和组信息，原实体脱离世界后也不解引用它；卸载部件留待完整占地加载并归属同一区域时检查孤立组。未知存档原样保留且拒绝自动组装/清理。

已知缺口：绊线承载方块仍没有来源的整格选择框与顶部 0.75–1.0 固体碰撞；这里只对齐了放置时的原生实体碰撞检测。岩浆点燃未实现。四格必须全部已加载且归属当前区域，Folia 跨区放置会拒绝；卸载或跨区不完整桌子的恢复清理仍待实服验证。如果外部回调令区域或区块在回滚前不可访问，事务报告错误且不会越区写入，可能留下部分状态。爆炸批量取掉落、并行区域破坏、热重载与原版客户端交互没有运行证据，不能据此保证整桌在全部环境中只掉一次。
