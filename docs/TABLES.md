# 厨房连接桌检查点

2026-11-17，来源 Cookery `2f4e386ce23f49a385ddf003c67fc6415c55417a`。本批是开发检查点，尚未完成实服与原版客户端验收。

## 操作与实现

11 种木材桌子已接入，连接沿 X/Z 单轴，保持来源的轴锁定规则、单桌/左端/中段/右端。每种桌子 8 个插件状态，全部来源几何分支经过检查；桌布在独立存档中保存，16 色 × 4 端型共 64 模型。

主手非地毯每次放一件，最多四件；创造模式也扣一件。空手从最后一件开始取出，在桌边生成掉落物。满桌和空桌空手返回 PASS。地毯单独铺桌布，换色扣一张并掉落旧桌布，同色不扣，空手不会取桌布。创造拆桌返还四格内物品但不返桌布；生存/非玩家移除返桌面内容和桌布。放置回滚不生成物品。

桌面物品保存完整现行物品 NBT（包括组件），兼容插件旧桌布存档。列表超过四个、数量不为一、类型/版本错误、不可读取物品或坏 envelope 会拒绝读取，保留原始数据并阻止交互/移除。无法序列化不会写入半份存档。回调重入、失效方块、保护拒绝、旁观者、跨区及旧实例不继续存取。

显示使用来源的 0.65 缩放、1.3125 基础高度、四组位置及 FIXED 视角，方块物品下调 0.25（随缩放）。取走内容会清理相应展示实体；桌布与物品跟随连接方向重画。
