# 蒸笼交互与双端运行验收

2026-11-17，开发检查点。来源仍固定为 Cookery `2f4e386ce23f49a385ddf003c67fc6415c55417a`，本地基线 `1d283d6`，修改尚未提交。未使用子代理。

## 本批行为

- 点击只操作当前蒸笼方块的四格或八格；使用实际触发的主手/副手。可蒸原料一次填满当前空格，每格一件；创造模式也按来源消耗原料。
- 放入不成功时，取出当前方块全部内容并保留完整数量。清空后的下一次点击拆除一个外露空层，返还一个空蒸笼；盖子或上方蒸笼阻止拆层。
- 空手潜行只切换点击位置的盖子。食物操作检查上方方块朝下的完整支撑面；底座和朝向按来源规则计算。允许放在普通非热源支撑面上，去掉人工叠高限制，仍受世界高度、区块加载和区域归属限制。
- 拆层检查交互/破坏权限并发送破坏事件；状态写入使用事务与重入保护。取消或失败恢复原内容，外部回调替换方块时保留替换结果并返还原蒸笼内容。
- 下落实体不再覆盖其他插件取消的落地事件；取消落地后只取一次待落数据并清理实体。

新回归覆盖副手、一次填空/取全、空层拆除、取消/重入/回滚、落地取消和普通支撑。与前批固定槽位、物品编解码、两条填充蒸笼配方一起构建。

## 本轮兼容修复

Paper 1.21.1 的 Gson 2.10.1 没有 `JsonReader.setStrictness`。现在使用其支持的接口并增加 JSON 词法校验，仍拒绝大小写错误的字面量、原始控制字符、非法转义/数字、重复键及多根对象。`testLegacyGson` 以真实 Gson 2.10.1 重跑目录测试，并加入 CI/本地构建入口。

CE 配置合法的空键方块状态会触发旧 Bukkit YAML 读取错误。来源索引现在先读取原始映射，仅把配方/工厂节点交给 Bukkit；同文件扫描共用锁和缓存。物品探针也改用原始映射读取。旧版菜单对包含空键的整份 YAML 执行写入仍需独立验收，不能由来源读取成功推断编辑成功。

验收插件声明最低 API 1.21。CraftEngine 26.9.1 在 26.3 的 `BonemealableBlockProxy` 初始化失败；官方 26.9.2 发布记录新增 26.3 支持。本轮运行服改用已核对官方 SHA-512 的 Paper 26.9.2 JAR；编译 API 仍为 26.9.1。

五插件共用的内部方块状态达到 6,045，超过原 6,000 配额；测试服改为 16,000。1.21.1 已核对厨房 81 方块的 5,599 内部状态全部注册，缺失/多余均为零。显式外观状态数不等于内部状态数。
