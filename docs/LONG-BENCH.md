# 长凳开发检查点

2026-11-17，固定 Cookery 来源 `2f4e386ce23f49a385ddf003c67fc6415c55417a`。本批实现长凳交互与资源，服务器和原版客户端尚未验收。

长凳放置轴与玩家水平朝向垂直：朝南北时沿 X，朝东西时沿 Z。只有同种、同轴长凳连接，邻居变化不改轴。西/北邻居决定左端，东/南邻居决定右端，两侧都有为中段；这与普通桌子的端点规则不同。四种源模型在 Z 轴旋转 90°，共八种状态，默认 X 轴单段。来源合成配方、硬度 2、抗爆 3、木声音和带 survives_explosion 的单件掉落已导入。

主副手、空手或持物均可右键乘坐；潜行或座位已占用时返回 PASS。每块长凳持有一个 CE 临时座位，沿 X 朝南、沿 Z 朝东。配置 Y 为 -0.35，加 CE 的 0.6 偏移后，目标乘坐锚点为来源的 0.5-0.25；真实玩家坐姿仍需客户端验证。交互不改变手持物品。

创建座位前检查玩家有效、在线、非死亡/旁观、同世界、玩家和方块区域归属、当前区块实体身份及保护权限。保护回调后重新检查；乘坐回调后再次确认方块身份、生命周期代次、轴向和实际载具。回调中拆除、替换、卸载再加载、递归点击、取消乘坐或重定向载具均不保留本次座位。拆除和卸载主动清理，重复/重入清理不会递归调用；已拆除控制器不能通过 onLoad 复活。
