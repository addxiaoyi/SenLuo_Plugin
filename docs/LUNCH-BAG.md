# 嬗变便当袋移植检查点

2026-11-17。依据 Cookery 固定提交 `2f4e386ce23f49a385ddf003c67fc6415c55417a` 的 `TransmutationLunchBagItem.java`。这是已编译、单元测试通过的开发实现，真人和原版客户端尚未验收。

## 操作与行为

- 24 个完整物品堆槽位，可放有食物组件的物品或普通药水；禁止饭袋嵌套。不用品质不同、效果不同或其他组件不同的堆叠互相合并。原插件 16 槽数据仍可读取。
- 在玩家背包或普通储物容器中，持袋右键食物或持食物右键袋子装入；对方为空时取出第一整堆。只扣实际装入量。机器的输入/结果等特殊槽位和旁观者不能使用此交换路径。
- 长按一次约 32 tick，依次吃到饱食度 20；仍访问后续普通药水。每份食物使用所属版本的原生 `finishUsingItem`，触发独立消费事件，返还原生余料，并通过既有厨房/酒馆监听器处理自定义效果和容器。
- 潜行左键倒出；空果篮从袋中装入，非空果篮向袋内转移可食用内容，空间不足保留余量。
- 每次消费在原生回调前写回剩余库存；同步重入、取消事件、旧手持快照拒绝再次消费。坏档保留原物品，不能解析的记录不当作空槽删除。
- 进食中丢弃会取消掉落，待服务器归还原物品后一 tick 恢复收纳形态，避免提前扫描遗漏。
- 合成沿用上游皮革与紫水晶配方，配置包含空/有内容模型以及进食形态。
