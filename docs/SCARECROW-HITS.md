# 稻草人受击窗口与晃动（2026-11-17）

接续 [内容与装备](SCARECROW.md)，本批替换通用家具的击打计数。固定来源 `ScarecrowEntity.hurt` 使用稻草人自身的 `lastHit`，在游戏 tick 差大于5时记录当前时间并晃动；差小于等于5时拆除。多个攻击者共享窗口，创造模式立即拆除。来源 `lastHit` 初始为0且不保存，因此世界刚开始前5 tick的首次击打可直接拆除；实现保留这一边界。冒险/旁观模式及保护拒绝不推进窗口。

CE26.9.2默认 `FurnitureHitData` 是每个玩家的墙钟两秒累计计数，不能用于该规则。资源包设置 `hit_times: 1`，使每次经过CE距离和BREAK权限检查的有效命中进入 `FurnitureBreakEvent`；厨房HIGHEST监听器执行来源窗口，首次晃动取消拆除，五tick内再次击打允许CE继续。先被其他监听器取消的事件不会推进窗口。CE随后执行的配置事件函数也能继续取消拆除或修改掉落。

最终事件对象暂存至同一tick的 `preRemove`，届时再次读取取消/掉落设置；下一tick丢弃引用。避免MONITOR后的配置函数变化被旧快照覆盖。事件 `dropItems=false` 同时抑制装备掉落；创造模式仍无本体/装备掉落。装备结算先于破坏粒子，粒子失败不会跳过库存处理。直接API移除仍沿用前序语义，只有接受的玩家破坏才标记玩家破坏效果。

首次击打播放来源盔甲架受击音，发送 `ENTITY_DAMAGE` 游戏事件。五tick晃动使用来源 `sin(elapsed/1.5*PI)*3°`，在家具ticker采样；默认身体、倾斜帽、头颅、双手装备均绕脚下原点转动，不移动命中箱。后来进入追踪范围或装备刷新会收到当前晃动姿势。停用鹦鹉功能时ticker仍运行晃动。已有肩膀载具只在停留严格超过20tick后受首击释放，但完整来源肩膀NBT/环境/距离逻辑仍未移植。

限制：20Hz采样与原模组逐渲染帧效果不同；客户端尚未对照。先于本插件取消的保护不触发动作，同一HIGHEST优先级较晚取消可能已播放首击反馈；拆除仍遵守最终取消。旧自备资源包必须更新为 `hit_times:1`，否则CE自身累计会让来源窗口只在部分命中时收到事件。爆炸、无敌绕过伤害、命名掉落、重力和矿车仍未实现。

单元测试覆盖5/6tick边界、同tick与创造规则、来源初始时间、晃动正负角度和支点、保护/冒险模式、卸载、晚取消/掉落规则。实服探针使用未注册到玩家列表、未登录的原生ServerPlayer对象，通过真实Bukkit/CE事件调用和移除API检查逻辑；没有修改online-mode或绕过登录鉴权，也不证明网络攻击包、真人点击或客户端渲染。

实服证据保留 g/29 的探针适配器缺少 `luck()` 失败；此时窗口/晃动检查已过，发放本体战利品时探针失败。补上默认幸运值后 g/30 完整通过。最终通过轮次及JAR哈希见 `docs/research/scarecrow-hit-runtime-2026-11-17.json`；所有失败轮次保留。
