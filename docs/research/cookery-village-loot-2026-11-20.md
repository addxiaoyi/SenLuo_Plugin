# 村庄战利品移植进展（2026-11-20）

本批实现固定来源资源导出、原生战利品 token 转换和失败抽签恢复，不包含五类厨房的自然生成池接入，也不构成实服或崩溃验收通过。

## 固定来源与导出

来源提交为 `2f4e386ce23f49a385ddf003c67fc6415c55417a`。导出器校验五份原始厨房 NBT、processor、村庄池追加规则、两张箱子 loot table、食谱抽签实现及所有食谱／标签依赖的哈希，未知规则或 NBT 状态拒绝导入。

两张箱子表保留原始顺序、抽取次数、权重、数量函数和 random sequence。菜谱使用同一原生 LootContext 的嵌套表，在来源顺序的 37 个等权选项中抽取；空白菜谱选项和重复原料保留，不由插件再次随机抽签。来源物品先编码成带专用 PDC 标记的纸张 token；插件仅转换这两张已知表中的已标记项，不改普通原版结果。

`village-loot.json` 的完整字节 SHA-256 为：

`2032a09155849f81000bd225780ccc526d775afb3e61b9d2f49440db6f92cf60`

Java 入口校验完整摘要后再解析；`.gitattributes` 将该资源标为 `-text`，防止 Windows 自动换行破坏摘要。来源模板仍导出在 `source/` 中，清单的 `naturalVillageIntegration` 保持 `NOT_IMPLEMENTED`，不能将这个 ZIP 当作可直接安装的自然生成数据包。

## 一代注册表内完成整次转换

有 token 的整次转换持有 CE 实际 `ResourceOperationCoordinator.Lease`，并在同一个外层 `FoodRecipeRegistry.readSnapshot` 中完成预检与全部物品工厂调用。前者排除 CE 资源重载，后者固定整次转换的配方快照；单独逐个物品读取快照不能保证这一点。

依赖未就绪、配方与固定来源不符、资源操作忙、未知 token、错误数量或无法构造物品时，转换失败并保留整次原生抽签；不会交付部分结果。普通无标记或其他表的事件保持原行为。该保证针对转换一致性，不是跨文件／世界存档的原子事务。

## 失败抽签恢复

失败记录写入插件数据目录 `village-loot-pending/<UUID>.json`，使用新建写入并 force；整份日志限制为 512 KiB，不覆盖已有日志。记录包含来源、原表、原世界和物理箱子位置、原物品快照及已经完成的原生抽签。

物理箱子的 PDC 使用小型 schema 3 指针，包含 UUID 与日志 SHA-256。原生 NBT `StringTag.write` 调用 `DataOutput.writeUTF`，有 65,535 modified-UTF 字节上限，因此不能把最多 512 KiB 的完整 JSON 放进一个 PDC STRING。合法旧 schema 2 完整 JSON 锚点仍可读取，并验证该原生大小限制。

恢复同时验证指针字段、日志摘要、UUID、来源、表、物理箱子身份、原库存和区域归属；缺失／篡改日志、错误 PDC 类型或不可读取的锚点均拒绝访问和交付。转换回调后再次读取箱子，确认同一个锚点与原库存；库存和 receipt 通过同一个箱子快照更新，再读回核对。有效 PENDING 与仍待抽取的来源 LootTable 同时存在时保持拒绝，不猜测哪份抽签应生效，也不再触发抽签。

打开、漏斗移动、玩家破坏与爆炸路径均保留上述防护。`/kcvillageloot recover <UUID>` 只在原箱子所属区域尝试恢复原抽签，不使用新的随机源。

**限制：** 日志、区块存档与物品提交不构成跨崩溃原子事务。日志成功而锚点尚未持久化等窗口可能留下孤立记录；它们需要人工核对，不能将该设计宣传为 crash-atomic exactly-once。

## 验证与下一步

本地固定来源导出测试 14 项通过。独立 `worldgen` 工作区全量 Java 636 项、78 套件通过，失败／错误／跳过均为 0；日志为 `build/village-bounded-validation-6.log`。其中包括资源摘要变异、真实 CE lease、整批快照发布、PDC 指针、70 KB 物品序列化和旧格式兼容。该分支基于较早的 `1149be8`，并入当前主线后仍须重跑组合检查。协议玩家、原生箱子随机抽签、正常重启、真实崩溃切点和跨 Folia 区域行为尚未实服验证。

自然厨房仍需完成原生模板迁移、有效池增量追加、CE 生成存储与 stove controller 实证，以及真正的在线重载／生成屏障；可复核的 API 调用链见[原生结构接入研究](cookery-village-native-integration-2026-11-20.md)。
